# МеталлОбработка — лендинг производства и склада металлопроката

Одностраничный сайт (лендинг) для компании, которая **сама держит склад металлопроката и сама обрабатывает металл**: режет лазером и плазмой, гнёт на листогибе, варит. Сделан для того, чтобы заменить «посредника с каталогом» на производство, где видно цену, срок и ответственного.
![Скрин главн стр](/images/Скриншот-метал-обработка.jpg).
> **Стек:** чистый HTML + CSS + JavaScript. Без сборки, без фреймворков, без зависимостей.
> Открывается двойным кликом по `index.html`. Идеально для GitHub Pages, любого статик-хостинга или папки на сервере.

---

## 1. Название

**МеталлОбработка · цех и склад** — лендинг металлообработки со склада металлопроката.

Домены, которые закрывает: `металлообработка`, `лазерный рез`, `листогиб`, `раскрой металла`, `запчасти для ворот`, `металлопрокат с резкой в размер`.

## 2. Решаемая задача

Производственник, который вкладывается в оборотку, регулярно попадает в три ситуации:

| Боль клиента | Как сайт её снимает |
|---|---|
| **Поставщик обещал «сегодня», а машина до сих пор не вышла** | Блок «Свой склад металла»: ходовой лист Ст3, 09Г2С, уголок и труба лежат в тоннах на соседней полке, запуск в работу — в день обращения |
| **Три цеха, три договора, ноль ответственности** | Блок «Единый производственный цикл»: свой склад, свой лазер, свой листогиб, свой сварочный пост. Один договор, один менеджер, одна точка ответственности |
| **Смета была 100 тысяч, счёт пришёл на 130** | Калькулятор на первом экране: видно стоимость каждого реза и гибки до копеек, цена фиксируется в момент оплаты, скрытых платежей за «сложность» нет |

Плюс коммерческая задача: **заявка не должна стоить звонка**. Калькулятор даёт цену без обращения, а форма обратного звонка, заказ из корзины и заявка с финального экрана — три точки входа, где менеджер получает готовый контекст (материал, размер, количество, операции, сумма), а не «расскажите, что вам нужно».

## 3. Пользователь

**Основной — производственник «средней руки»:** начальник производства, инженер, прораб, хозяин гаража. Часто принимает решение сам, без тендерного отдела, и ценит скорость и конкретику больше, чем лозунги.

| Аудитория | Что ищет на странице | Где мы это даём |
|---|---|---|
| Начальник производства (вентиляция, ворота, стройка) | Сроки, допуски, ответственность, сертификаты станков | Блок «Наше оборудование» с паспортными данными, шаги работы, отзывы |
| Инженер-технолог | Возможности: что режем, до какой толщины, точность | Калькулятор с операциями и раскроем, прайс металла с остатками |
| Прораб / снабженец | «Есть ли это в наличии и сколько стоит» | Каталог готовых запчастей (500 позиций) + корзина + остатки металла |
| Частный мастер | Одна деталь, без «закупки фуры металла» | Калькулятор от 1 шт, рез в размер, готовые детали со склада |

**Тон коммуникации:** без «инноваций» и «синергии». Цифры, сроки, допуски, цена до копейки. Каждый блок отвечает на возражение, а не на вопрос «чем вы занимаетесь».

## 4. Что умеет сайт

### 4.1 Калькулятор стоимости (первый экран)
* **Материал:** Ст3, 09Г2С, AISI 304, AISI 430 — с разной плотностью, ценой за кг и коэффициентом скорости реза.
* **Толщина:** 1–20 мм (для нержавейки — до 12 мм), с подсветкой ходовой позиции 3 мм.
* **Габариты и количество:** от 1 шт, минимум не предусмотрен.
* **Операции:** лазерный рез, плазменный рез, гибка (включается тумблером, количество гибов на деталь — отдельным полем).
* **Длина реза:** считается автоматически по периметру детали с коэффициентом 1,25 (запас на внутренние элементы и отверстия), но поле редактируется — как только пользователь правит его руками, автоподстановка отключается.
* **Срочность:** стандарт (2 дня), +15% (1 день), +30% (вчера).
* **Чертёж:** drag & drop для `.dxf`, `.dwg`, `.pdf`, `.step` — имя файла подхватывается в смету.
* **Живой расчёт:** пересчёт на каждый ввод, анимированная смена итога, детализация бюджета по статьям (материал / рез / гибка / наладка и контроль / срочность).
* **PDF-смета:** кнопка формирует документ с разбивкой и открывает его в режиме «Сохранить как PDF» с понятным именем файла, параллельно уходит заявка в таблицу и письмо на почту.

Формулы (см. `script.js`, раздел `calcState`):

```
масса детали, кг  = (Д × Ш / 1e6) × толщина × плотность
стоимость металла  = масса × цена за кг
скорость реза, м/мин = (14 − 1,05 × толщина) / коэффициент материала
время реза, ч      = (длина реза × кол-во) / 1000 / скорость / 60
стоимость реза     = время × 2 600 ₽/ч
гибка              = гибы × кол-во × 340 ₽ + кол-во × 240 ₽ (зажим)
наладка и контроль = 2 200 ₽ + технологические надбавки + 180 ₽ × ceil(кол-во / 20)
```

### 4.2 Склад металла
Карточки по видам проката (листовой, труба, сортамент) с размерами в наличии, кнопка **«Посмотреть остатки металла и цены за кг/лист»** открывает модальное окно с прайсом по трём вкладкам (листовой / труба / сортамент): цена за кг, остаток в тоннах, кнопка «В расчёт» — переводит к калькулятору.

### 4.3 Склад готовых запчастей + корзина
* Каталог на **500 позиций** (5 категорий × 10 товаров × 10 типоразмеров): ворота и роллеты, стройка и крепёж, вентиляция, стеллажи, водоснабжение.
* Поиск по названию, артикулу и категории, фильтр «только в наличии», сортировка по цене/популярности/названию, догрузка по кнопке.
* Корзина в `localStorage` (переживает перезагрузку), изменение количества, удаление, счётчик в шапке, оформление заказа с адресом доставки.
* Микротекст снятия возражений: наличие обновляется раз в сутки, резерв на 24 часа.

### 4.4 Формы и заявки
Три формы (заявка с финального экрана, обратный звонок в модальном окне, заказ из корзины) плюс расчёт из калькулятора — **все пишутся в Google Таблицу** (раздел 6) и дублируются письмом, если скрипт недоступен. Валидация полей, маска телефона, снятие ошибок на лету, тосты с подтверждением.

### 4.5 Остальное
Блок «Как решаются эти боли» (3 карточки боль → решение), оборудование с паспортными данными и загрузкой станков, 4 шага работы, отзывы с KPI, FAQ-аккордеон, финальный CTA с запасом листа 3 мм, футер с реквизитами и P.S. про ручной расчёт.

## 5. Дизайн

Тёмная база `#08090b` с оранжевым градиентом (`#ff6a00 → #ff9e3d → #ffd36e`), стеклянные карточки на `backdrop-filter: blur(22px)`, крупные акцентные кнопки с подсветкой и бликом.

| Приём | Реализация |
|---|---|
| Появление блоков | `IntersectionObserver` + CSS-анимации с задержкой `--d` (fade + подъём + размытие) |
| Parallax | Орбы фона и свечение финального блока смещаются от скорости скролла (`requestAnimationFrame`, без jank) |
| Hover | Подъём карточек, spotlight-подсветка под курсором (`--mx/--my`), 3D-tilt калькулятора, sheen-блик по кнопкам |
| Микро-интерактив | Счётчики, анимированные шкалы, пульсирующие точки, липкая шапка с прогресс-баром скролла, мобильная CTA-панель |
| Доступность | `prefers-reduced-motion` отключает анимации, семантическая разметка, `aria-label` на иконочных кнопках, фокус-кольца |

## 6. Заявки → Google Таблица

В папке `apps-script/Code.gs` лежит готовый скрипт. Он принимает POST и дописывает строку в таблицу.

**Настройка (один раз):**

1. Откройте таблицу заявок → **Расширения → Apps Script**.
2. Вставьте код из `apps-script/Code.gs` в `Code.gs`, сохраните.
3. **Развернуть → Новое веб-приложение:**
   * Выполнять как: **Я** (иначе скрипт не сможет писать в таблицу)
   * Доступ: **Любой** (иначе сайт не сможет отправлять)
4. Скопируйте ссылку, заканчивающуюся на `/exec`, в `script.js`:

   ```js
   var LEADS = {
     endpoint: 'https://script.google.com/macros/s/.../exec',
     fallbackEmail: CONTACT.email,
     utm: readUTM()
   };
   ```

5. Отправьте тестовую заявку — строка появится в таблице. Проверка скрипта: открыть `/exec` в браузере, должен вернуться текст «OK».

**Колонки таблицы** (создаются автоматически при первой заявке): дата и время · тип заявки · имя · телефон · e-mail · тема/задача · комментарий · адрес доставки · сумма · позиции заказа · расчёт из калькулятора · страница · UTM-метки · статус · менеджер.

**Важно:**
* Пока `endpoint` не заполнен, заявки уходят письмом на `CONTACT.email` — сайт полностью работоспособен без Apps Script.
* Если скрипт временно недоступен, заявка автоматически уходит письмом — заявки не теряются.
* Запрос отправляется в режиме `no-cors` (Google не отдаёт CORS-заголовки), поэтому фронтенд не может прочитать ответ скрипта — это осознанный размен на надёжность.
* После правки кода в Apps Script нужно **переразвернуть** приложение: «Развернуть → Управление развёртываниями → ✏️ → Обновить».
* Опционально: запустить `setupSheet()` один раз — создаст лист, заголовки, ширины колонок и триггер уведомлений на почту.

## 7. Структура проекта

```
.
├── index.html            # разметка всей страницы (840 строк)
├── styles.css            # тема, стекло, анимации, адаптив (824 строки)
├── script.js             # вся логика: калькулятор, каталог, корзина, формы, motion (1080 строк)
├── apps-script/
│   └── Code.gs           # бэкенд приёма заявок для Google Таблицы
└── README.md
```

**Разделы `index.html`:** header → hero + калькулятор → «как решаются боли» → склад металла → склад запчастей и каталог → оборудование → как работаем → отзывы → FAQ → финальный CTA + форма → футер → модалки (форма, прайс), корзина-drawer, тосты.

**Ключевые модули `script.js`:**

| Модуль | Ответственность |
|---|---|
| `initReveal` / `initParallax` / `initCounters` | появление блоков, параллакс, счётчики |
| `initHeader` | липкая шапка, прогресс скролла, бургер-меню, мобильная CTA |
| `initPointerFX` | spotlight по курсору, 3D-tilt |
| `calcState` / `renderCalc` / `printEstimate` | расчёт, разбивка бюджета, PDF-смета |
| `initCatalog` / `renderCart` / `addToCart` | каталог, фильтры, корзина в `localStorage` |
| `initPrice` | прайс металла в модальном окне |
| `submitLead` / `leadText` / `leadMailto` | отправка заявки в таблицу с фолбэком на почту |
| `validate` / `initMask` | валидация форм и маска телефона |

## 8. Запуск и развёртывание

**Локально:** открыть `index.html` в браузере. Всё работает по `file://`, включая отправку заявок.

**GitHub Pages:**

```bash
git init -b main
git add .
git commit -m "Лендинг МеталлОбработка"
gh repo create Matalin25/metall-obrabotka-landing --public --source=. --remote=origin --push
# затем Settings → Pages → Source: Deploy from a branch → main / (root)
```

**Любой другой хостинг:** загрузите содержимое папки в корень сайта (nginx, Apache, S3, Netlify, Vercel). Серверная настройка не нужна.

## 9. Что заменить перед запуском в прод

| Где | Что |
|---|---|
| `script.js` → `CONTACT` | телефон, почта, адрес |
| `script.js` → `LEADS.endpoint` | ссылка на развёрнутый Apps Script |
| `script.js` → `PRICE` | цены за кг и остатки металла |
| `script.js` → `TEMPLATES`, `CATS` | реальный ассортимент запчастей вместо сгенерированного |
| `script.js` → `MAT`, `MACHINE` | цены металла, ставка станка, пороги скорости реза |
| `index.html` → тексты блоков «Оборудование», «Отзывы», «FAQ» | реальные паспорта станков, реальные отзывы |
| `index.html` → `href` на WhatsApp/Telegram | ваш номер |
| `index.html` → `data-wa` / ссылки в футере | реквизиты, политика, договор |

> Цены в калькуляторе — демонстрационные. Алгоритм в `calcState` нужно откалибровать по вашим фактическим ставкам: себестоимость часа станка, стоимость оснастки, логистика.

## 10. Совместимость

Chrome / Edge / Firefox / Safari актуальных версий, десктоп и мобильные. Используются `backdrop-filter`, `aspect`-независимые гриды, `IntersectionObserver`, `fetch` с `keepalive`, CSS-переменные. При `prefers-reduced-motion: reduce` анимации отключаются, контент остаётся читаемым. Без JavaScript страница остаётся читаемой (блоки видимы), но калькулятор и корзина, разумеется, не работают.
